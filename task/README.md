# 丰云行非登录 Issue 原始问题 UI Demo

本工程从 `fyxapphos` 登录页修复之后的近期 UI issue 提交中，反向提取修复前的关键布局约束，形成一个无业务依赖的纯 UI 复现工程。登录页不在本工程范围内。

## 页面与提交映射

| 页面 | 修复提交 | 保留的问题实现 |
| --- | --- | --- |
| 设置页内容溢出 | `764c9856` | 无滚动长列表、`lpx` 字体和底部退出按钮 |
| 服务页比例失真 | `764c9856` | `209lpx` 页头、`83lpx` Tab 和固定比例控件 |

| 服务页 Tab 白底与内容重叠 | 8 月 7 日 `642adb45` 快照，修复见 `764c9856` / `4c2eaf1c` | 正常流起点为 `292lpx`，内容却被绝对定位到 `149lpx`，实际向上错位 `143lpx` 并钻入 Tab 下方 |

每个问题页只使用 ArkUI 基础组件，互相不引用，也不依赖 `fyxapphos` 的网络、路由封装、WebView、状态管理、图片接口或业务模块。

## 复现建议

在手机竖屏先观察基线，再切换横屏、平板、2in1 或自由窗口并缩短窗口高度。服务页问题默认展示“体验车”重叠现场，可切换“保客”状态；向上滑动后 Tab 会吸顶。页面中的“返回”入口可回到导航首页。
